# Quotes to code by

> Make it work, then make it beautiful, then if you really, really have to, make it fast.  
> 90 percent of the time, if you make it beautiful, it will already be fast.  
> So really, just make it beautiful!

_Joe Armstrong_, [Erlang and OTP in Action - Martin Logan, Eric Merritt, and Richard Carlsson](https://www.manning.com/books/erlang-and-otp-in-action)
